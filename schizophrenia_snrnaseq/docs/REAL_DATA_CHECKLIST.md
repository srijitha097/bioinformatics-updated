# Scientific validity checklist before GitHub or resume

- [ ] Source dataset accession and paper (for provenance) included in README.
- [ ] Confirm data input is REAL, not synthetic, and output provenance is saved.
- [ ] Confirm gene identifiers align and there are no duplicates.
- [ ] Confirm independent units (donor or brain section) for statistical claims.
- [ ] Confirm sample inclusion/exclusion and missingness.
- [ ] Confirm batch, age, sex, postmortem interval and other confounding checks where available.
- [ ] Confirm QC figures and FDR-adjusted statistics are interpreted correctly.
- [ ] Write limitations and compare with null or negative-control analysis where practical.
- [ ] Do not commit patient/sample-linked raw counts or restricted metadata.
- [ ] Only use results-based resume bullets after inspecting the actual data analysis.
